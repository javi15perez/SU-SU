# SUSU MVP
Mobile-first PWA personal para nutrición, actividad y progreso.

## Ejecutar
Sirve esta carpeta con cualquier servidor estático. Ejemplo: `python3 -m http.server 8080` y abre http://localhost:8080.

## Ya funciona
- Dashboard diario kcal/proteína
- Favoritos de comida
- Registro manual de comida
- Contador rápido de flexiones y dominadas
- Reto de flexiones
- Persistencia local sin backend ni coste
- Manifest PWA
